# PRPD t-SNE Analysis Tool

This tool reads a single `.dat` file as 1-minute data.

- Header: Default 227 bytes, some files 167 bytes
- Payload: `uint8`, `128 × 3600 = 460,800` bytes
- 128: phase bins
- 3600: 1-minute time samples

## Execution

```powershell
python -m pip install -r requirements.txt
streamlit run PRPD_Analyzer/app.py
```

The default data folder is `Data/by_type`. The folders `Lab_PD`, `Field_PD`, `Lab_Noise`, `Field_Noise`, and `Randomly_Generated` are recognized as `Lab PD`, `Field PD`, `Lab Noise`, `Field Noise`, and `Synthetic` groups respectively. Dates are extracted from the filename in the `by_type` structure, and from the date folder in the `by_date` structure. The default group filters are `Lab PD`, `Field PD`, `Lab Noise`, and `Field Noise`. The two Noise groups are compared separately on the summary screen.

Even if `Data/by_date` is selected, the `Lab`, `Field`, and `Artificially_Generated` folders are converted to the same analysis groups, so both folder structures can be used. Since `by_date` and `by_type` are just different classification views of the same data, only one root is analyzed at a time. Each file becomes one point in t-SNE. The 256-dimensional feature (128 phase-wise time means + 128 time maximums) is standardized before applying t-SNE.

The web dashboard includes summary statistics, group quantities by date, mean/max phase features, original PRPD images, t-SNE results, error files, and CSV download screens. To analyze all files, select `Lab PD`, `Field PD`, `Lab Noise`, `Field Noise`, and `Synthetic` in the group filter and set the maximum number of samples to the total number of files.

### How to Read the Category Report

The scores in the `Category 리포트` (Category Report) tab indicate the **priority order for human review of original PRPDs**, not auto-reclassification results. The category of a file will not be automatically changed.

- `suspect_score` — Pooled shrinkage Mahalanobis distance d² based on the `(group, label)` cell. Shows how far it deviates from its own category distribution.
- `margin` — `suspect_score − d2_nearest`. **If positive, another category center in the same group is closer**, providing direct evidence of suspected mislabeling. Even if negative, a large d² may indicate data quality anomalies.
- `Top 1%` / `Top 5%` — **Empirical percentiles** based on all valid files. This is not an absolute standard, meaning it's not "1% are wrong," but rather "the first 1% to review." The theoretical chi-square critical value is not used because distances are compressed due to shrinkage.
- `reference_status = insufficient` — Files where the baseline distribution couldn't be created because the cell sample size was under 10. This means there is no score, not that it is normal, so they are separated into a different list.

The `Feature 품질 진단` (Feature Quality Diagnostics) table is a **diagnostic tool** to compare how well `Mean` / `Max` / `Mean+Max` separate the PD classes. It is not a classifier and is not used for the scores above. Since silhouette cannot distinguish between `max` and `mean+max` in this data, we also look at the date-wise CV macro F1. The rationale numbers can be found in section 6 of [claude.md](claude.md).

```powershell

The noise group is not used; instead, the paper's parametric CIN (white + pink + power-frequency narrowband) is used.

### Data Format

The payload is stored as **cycle-wise records** — `3600 cycle × 128 phase bin`, where phase is the continuous axis. The parser reads this as `(3600, 128)` and then transposes it to pass `(phase=128, time=3600)`. Standard files use a 227-byte header, one specific field Noise file uses a 167-byte header, and both formats share the same 460,800-byte payload.

> **Updated 2026-08-25.** Previously, the parser immediately applied `reshape(128, 3600)` to the payload. Because `3600 % 128 = 16`, values of different phases were shifted and mixed into each "phase row", and the phase-wise mean/max features were not values of the same phase. Evidence: payload autocorrelation lag 128 = 0.978 vs lag 3600 = 0.192. Details are in section 2.1 of [claude.md](claude.md), regression tests in `tests/test_io.py`. **All `artifacts/ai_data_*` folders and diffusion run results generated before this date are invalid and marked in `STALE_AXIS_BUG.md` in each folder.**

To analyze all data, check `전체 데이터 분석 (필터 무시)` (Analyze All Data - Ignore Filters) on the sidebar and run. To create an AI dataset via CLI instead of UI, use `python PRPD_Analyzer/scripts/build_ai_dataset.py`.
